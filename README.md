# PDF Text Extractor & Analyzer

## Objective
Extract text from PDF documents and analyze their content using Bash shell scripting, regular expressions, and AWK.
## Features
- PDF text extraction
- Date extraction using regular expressions
- Phone number extraction using regular expressions
- Keyword searching
- Keyword occurrence counting
- Word frequency analysis using AWK
- Top 10 frequently occurring words
- Document statistics
- Automated report generation
- Error handling

## Tools Used
- Bash
- pdftotext
- awk
- grep
- sort
- wc
- Git
- Ubuntu

## Installation
sudo apt install poppler-utils gawk

## Execution
1. Place a PDF file inside the input folder.
2. Run chmod +x main.sh
3. Run ./main.sh
4. Enter the PDF filename.
5. Select an option from the menu.
